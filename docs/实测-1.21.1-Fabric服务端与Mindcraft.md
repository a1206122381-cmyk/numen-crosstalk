## 二、我预判错了一件事（值得记）

**我原本预测 crosstalk 会在专服上崩**，因为它引用了 `net.minecraft.client.*`：

```
NameResolver  → MinecraftClient / ClientWorld / PlayerEntity
EventPump     → 通过反射碰 EntityAgentLoop
```

**实际没有崩。** 原因是：

> 那些 `client.*` 类**只在工具被调用时才加载**，而专服上 Numen 不跑 agent loop
> （大脑在客户端），工具永远不会被调用。所以那些类根本不会被类加载器碰到。

日志证据：
```
[crosstalk] 管道目录 = D:\Minecraft\fabric-1.21.1-server\config\crosstalk
[crosstalk] 已注册工具: say / hear / who_is_here
[collab]    已挂上协作说明（219 字符）
```

**这是个"刚好能用"的结果，不是设计出来的。** 它成立的前提是"专服上工具永不被调"。
如果哪天 Numen 让专服也能跑大脑，这里就会崩。

**要不要主动改成客户端专属加载**（`@Environment(EnvType.CLIENT)` 之类）？
我倾向前者——**保持现状，但把这条前提写进注释**，因为做懒加载改造的收益不明确。

### 3.2 ⚠️ 一条真实的限制：**Fabric API 会触发注册表解析错误**

连接时会出现：

```
PartialReadError: Read error for undefined :
  Missing characters in string, found size is 108271 expected size was 114153
    at Object.ArmorTrimMaterial (...)
```

**成因**（我的判断）：

服务器装了 `fabric-registry-sync-v0 5.3.2`（Fabric API 的子模块），
它会把**扩展过的注册表**发给客户端。而 Mineflayer 的 1.21.1 协议定义是按**原版**写的，
字段长度对不上 → 解析在 `ArmorTrimMaterial` 那里失败。

**影响范围：只是启动时的一条日志噪声。**
上面 9 项功能测试全部通过，包括真实动作和收发包。

**为什么还值得记下来**：

> 这正是"**Mindcraft 对模组整合包的有限兼容**"的具体形态——
> **任何往注册表里加东西的 mod 都会触发它。**
>
> 而这次测的是**只有 Fabric API、没有内容 mod** 的情况。
> 装了真正的模组（Create / AE2 / Mekanism）后，注册表偏移会更大，
> 那时**可能就不只是噪声了**。

### 3.3 一个有用的发现：**Fabric 服不需要 Forge 握手**

本项目有个 `forge-handshake` 模块（逆向实现，让 Mineflayer 连 Forge 服）。
**Fabric 服不需要它** —— 直接 `createBot` 就能连。

这印证了它的定位：**那是个 Forge 专属的兼容层**，不是通用必需品。

## 四、服务端侧 crosstalk 的现状

专服上创建了：

```
config/crosstalk/collab-prompt.txt   225B
```

**注意没有 `speech.jsonl`** —— 因为没有任何同伴调过 `say`。
这是对的：**专服上没有大脑，没有人会调工具。**

**所以 crosstalk 在专服上是"装好了但不工作"的状态。** 这符合 Numen 的架构
（大脑在客户端），也符合本项目的定位（它是给同伴用的，不是给专用服务器用的）。

## 六、复现步骤

### 起服务端

```powershell
cd D:\Minecraft\fabric-1.21.1-server
& 'C:\Program Files\Eclipse Adoptium\jdk-21.0.12.8-hotspot\bin\java.exe' `
  -Xmx2G -jar fabric-server-launch.jar nogui
```

**踩过的两个坑**：
1. `level-type=minecraft:flat` 在 1.21.1 上会报 `No key layers in MapLike[{}]` ——
   要显式给 layers，**或者干脆用默认 normal**（我用了后者）
2. 换端口后重启前**必须确认旧进程真的退了**，否则
   `IOException: 另一个程序已锁定文件的一部分`（session.lock 被占）

### 测 Mindcraft 连接

```javascript
// 放在 mindcraft/ 目录下才能找到 node_modules
import mineflayer from 'mineflayer';
const bot = mineflayer.createBot({
    host: '127.0.0.1', port: 25571,
    username: 'probe', version: '1.21.1', auth: 'offline'
});
bot.once('spawn', () => { console.log('✅', bot.entity.position); bot.quit(); });
```

**不要装 forge-handshake** —— 那是给 Forge 服用的。
