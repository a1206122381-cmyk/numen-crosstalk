## 0. 你需要什么

| 组件 | 必须吗 | 说明 |
|---|---|---|
| Minecraft **1.21.1** + **Fabric** 加载器 | ✅ | 目前只做了这个版本 |
| [Fabric API](https://modrinth.com/mod/fabric-api) | ✅ | Numen 的前置 |
| [Numen](https://github.com/Dwinovo/minecraft-numen) | ✅ | 本体 + `numen-api` 两个 jar |
| **CrossTalk**（本仓库） | ✅ | `crosstalk-fabric` |
| **CrossTalk Collab** | ⬜ 可选 | 改提示词那一句，见 §1.3 |
| **speech-mcp** | ⬜ 可选 | 只在你要接外部工具时需要 |

## 1. 装 mod

### 1.1 拿 jar

从 [Releases](../../releases) 下载，或者自己构建：

```bash
cd packages/numen-crosstalk-fabric
./gradlew build
# 产物：build/libs/crosstalk-fabric-<版本>.jar
```

**构建前置**：`libs/` 目录下要有一份 `numen-api-fabric-1.21.1-<版本>.jar`
（编译期用来确认 Numen 侧的签名）。从
[numen-maven](https://github.com/Dwinovo/numen-maven) 取：

```
https://raw.githubusercontent.com/Dwinovo/numen-maven/main/com/dwinovo/numen/numen-api-fabric-1.21.1/<版本>/numen-api-fabric-1.21.1-<版本>.jar
```

> 注意：这个 jar **不进版本库**（`.gitignore` 已排除）。
> 换 Numen 版本时要同步换它。

### 1.2 丢进 mods

`.minecraft/mods/` 里应该有这四个（外加可选的第五个）：

```
fabric-api-<版本>.jar
numen-fabric-1.21.1-<版本>.jar
numen-api-fabric-1.21.1-<版本>.jar
crosstalk-fabric-<版本>.jar          ← 本仓库
crosstalk-collab-<版本>.jar          ← 可选，见下
```

### 1.3 要不要装 Collab？

**这是唯一一个会改变同伴行为的组件**，所以单独拆出来了。

| | 只装 `crosstalk-fabric` | 加上 `crosstalk-collab` |
|---|---|---|
| 同伴手上的工具 | `say` / `hear` / `who_is_here` | 同左 |
| 它的系统提示词 | **一字不改** | 每轮多一句协作说明 |
| 行为 | 和没装 mod 时一样，只是多了工具 | 它知道"话也可以对同伴说" |

**装法**：把 jar 丢进 mods 就行，零配置。

**想改那句话**：编辑 `config/crosstalk/collab-prompt.txt`，**改完立即生效，不用重编译**。
首次启动会自动生成默认文本。

**它怎么改提示词的**：用 Numen 官方的 `contributeState` 钩子，每轮请求现算一段挂进
`<runtime_state>`。**不碰 `config/numen.json`**（改别人的配置文件是侵入性的，
而且会和用户自己的设置打架）。这个钩子挂在请求末端，不进那个字节级稳定的系统提示，
所以**打不碎 prompt 缓存**。

## 2. 配置 Numen（模型）

**这一步和本 mod 无关**——本 mod 不碰任何 Numen 配置。但没配模型的话同伴不会说话。

### 2.1 图形界面（推荐）

进游戏 → 按 **`G`** → **设置** → **模型** → 选一家 → 粘贴你自己的 API key。

### 2.2 或者直接编辑文件

`config/numen.json`：

```json
{
  "apiKey": "你的 key",
  "provider": "deepseek",
  "model": "deepseek-chat",
  "baseUrl": "https://api.deepseek.com/beta",
  "systemPrompt": "..."
}
```

| 字段 | 说明 |
|---|---|
| `apiKey` | **必填**。你自己的 key，只存本地，不经过任何第三方 |
| `provider` | 选一个：`openai` / `deepseek` / `moonshot` / `minimax` / `volcengine` / `dashscope` |
| `model` | 后端认识的名字就行 |
| `baseUrl` | **留空**用 provider 默认；只有自建代理或非默认区域才填 |
| `systemPrompt` | **别动**。本 mod 不改它；要加协作那句请用 Collab |

> ⚠️ **改完必须重启游戏**，这个文件只在启动时读。

### 2.3 关于 systemPrompt

Numen 出厂的默认是：

> You are Numen, a Minecraft entity controlled by the player who owns you.
> Use the tools provided to act in the world; output text only to talk to your owner.

**本 mod 刻意不改它。** 理由：一般化工具不该附带提示词定制，
否则每个装它的人都会得到不一样的行为。

如果你想要"话也可以对同伴说"那层意思，装 `crosstalk-collab`——
它把这件事**单独**做出来，别人一眼能看出装了什么。

## 3. 起 speech-mcp（可选）

**只在你要接外部工具时需要。** 只用游戏内同伴的话，跳过这节。

它是个独立的 Node 进程，通过 MCP 协议暴露三个同名工具给**任何** MCP 客户端。

```bash
cd packages/speech-mcp

node index.mjs \
  --port    9101 \
  --speaker Lin \
  --out     <你的目录>/speech.jsonl \
  --heard   <你的目录>/heard.jsonl
```

| 参数 | 说明 |
|---|---|
| `--port` | 监听端口 |
| `--speaker` | 谁在通过这个实例说话。**不设的话**就用调用时的 `as` 参数自报名字 |
| `--out` / `--heard` | 两个文件路径。要和 mod 的 `config/crosstalk/` 指向同一处才能互通 |

也支持环境变量：`SPEECH_MCP_PORT` / `SPEECH_MCP_SPEAKER` / `SPEECH_MCP_OUT` / `SPEECH_MCP_HEARD`。

**测试**：

```bash
node packages/speech-mcp/index.mjs --port 9202 --speaker TestA \
  --out   /tmp/t-speech.jsonl \
  --heard /tmp/t-heard.jsonl

node packages/speech-mcp/test/integration.mjs 9202
# 预期：18 通过 / 0 失败
```

### 接进 Numen 的内置 MCP 客户端

`config/numen/mcp_clients.json`：

```json
{
  "enabled": true,
  "servers": [
    {
      "name": "crosstalk-speech",
      "type": "http",
      "url": "http://127.0.0.1:9101/mcp",
      "headers": {},
      "enabled": true,
      "connect_timeout_seconds": 20,
      "call_timeout_seconds": 60
    }
  ]
}
```

> ⚠️ **一个已知限制**：MCP 协议里**没有"谁在调用"这个字段**——
> 工具调用只带工具名和参数。所以外部 MCP 服务器分不清是 Lin 在说还是 Wei 在说。
>
> **要区分身份就用游戏内的 mod 工具**（它从 `ToolCall.ctx()` 拿 UUID）。
> MCP 那条路适合"只要一个嘴巴、不关心署名"的场景。

## 4. 验证装好了

启动游戏，看日志里有没有：

```
[crosstalk] 管道目录 = <游戏目录>/config/crosstalk
[crosstalk] 已注册工具: say / hear / who_is_here
[crosstalk] 已接上事件通道: EntityAgentLoop          ← 自动投递可用
```

（装了 Collab 的话还有：）

```
[collab] 协作说明来自 <游戏目录>/config/crosstalk/collab-prompt.txt
[collab] 已挂上协作说明（219 字符）
```

然后**召唤一只同伴**（`G` → 左栏 `+` → 起名），问它一句让它说话。

**成功的标志**：`config/crosstalk/speech.jsonl` 里出现一行，**署名是同伴的名字**：

```json
{"seq":1,"t":1790749850807,"name":"AAA","text":"..."}
```

**署名是 UUID 而不是名字也不要紧**——功能可用，只是难读（见 §5）。

## 5. 常见问题

### 同伴说 "could not read the list of who is here"

`who_is_here` 读不到玩家列表。**这是诚实的失败，不是撒谎**——
它有意识地区分了"确认没人"和"我查不到"。

看日志里有没有更具体的：
```
[crosstalk] 读世界玩家列表失败: ...
[crosstalk] who_is_here：从世界玩家列表读到 N 个个体
```

### 同伴的署名是 UUID 前 8 位

名字解析失败，退化了。功能仍可用。通常是 Numen 改了内部类名——
`NameResolver` 里的反射路径需要跟着改。

### 同伴不会主动听别人说话

检查日志里有没有这一行：
```
[crosstalk] 已接上事件通道: EntityAgentLoop
```

没有的话说明这个 Numen 版本没有 `pushEvent(String,String,long,boolean)`，
此时**只有 `hear` 工具可用**（得有人提醒它去听）。

### 改了配置没生效

`config/numen.json` **只在游戏启动时读**。改完要重启。

`config/crosstalk/collab-prompt.txt` 是**每次启动时读**的，也要重启。
